# Oi, eu sou a Mariana 👋

### Designer gráfica, UX/UI designer e ocasionalmente culpada por aplicações funcionando.

Sou formada em Design Gráfico e trabalho principalmente com interfaces, identidade visual, sistemas de design e organização de informações.

Gosto especialmente daquela fase em que um projeto ainda é uma bagunça: entender necessidades, levantar requisitos, prever fluxos, descobrir regras de negócio e transformar tudo isso em alguma coisa que faça sentido para seres humanos.

**Código não é minha profissão.**

Mas às vezes meus protótipos começam a funcionar. 🤷‍♀️

#### 📖 Teologia Reversa

Um estudo sobre **contradições, tensões narrativas e diferentes versões presentes nos textos bíblicos**, desenvolvido a partir de pesquisa, comparação de passagens e organização da informação.

Não é um projeto sobre dizer no que alguém deve acreditar — é sobre **olhar para o texto, fazer perguntas e investigar o que acontece quando diferentes trechos são colocados lado a lado**.

> ⚠️ Contém análise crítica de textos religiosos.  
> Textos e ideias podem ser questionados. Pessoas, não.

[📚 **Conhecer o projeto →**](https://github.com/maturbuk/Teologia-Reversa) · [🌐 **Explorar Teologia Reversa →**](https://maturbuk.github.io/Teologia-Reversa/)
