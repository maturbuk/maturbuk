# Oi, eu sou a Mariana 👋

### Designer gráfica, UX/UI designer e ocasionalmente culpada por aplicações funcionando.

Sou formada em Design Gráfico e trabalho principalmente com interfaces,
identidade visual, sistemas de design e organização de informações.

Gosto especialmente daquela fase em que um projeto ainda é uma bagunça:
entender necessidades, levantar requisitos, prever fluxos, descobrir regras
de negócio e transformar tudo isso em alguma coisa que faça sentido para
seres humanos.

**Código não é minha profissão.**

Mas às vezes meus protótipos começam a funcionar. 🤷‍♀️
